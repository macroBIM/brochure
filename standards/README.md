# 도로 옹벽 · 암거 표준도 데이터

국토교통부(옛 건설교통부 · 국토해양부)가 발행한 **도로 옹벽 표준도**와 **도로암거표준도**의 치수 · 철근 · 재료표를 표 형식(CSV · JSON)으로 옮긴 데이터입니다.
표준도는 누구나 볼 수 있는 공개 자료이고, 여기서는 그 값을 컴퓨터로 다루기 쉽게 정리만 했습니다.

- 표로 보기: `index.html` (GitHub Pages 를 켜면 `https://macrobim.github.io/brochure/standards/` — 블로그에 `<iframe>` 으로 넣을 수 있습니다)
- 파일 바로 받기: `https://raw.githubusercontent.com/macroBIM/brochure/main/standards/retaining-wall/L.csv` 처럼
- 만든 곳: [macroBIM](https://www.macrobim.com)

## 들어 있는 것

| 폴더 | 내용 | 원본 |
|---|---|---|
| `retaining-wall/L.csv` | L형 옹벽 (27매) — 높이 · 성토 · 경사 · 지진 조건별 치수와 부호별 철근 (직경 · 개수 · 길이 · 간격) | 도로 옹벽 표준도 (건설교통부, 2003) |
| `retaining-wall/T.csv` | 역T형 옹벽 (35매) | 〃 |
| `retaining-wall/H.csv` | 반중력식 옹벽 (36매) | 〃 |
| `box-culvert/` (준비 중) | 박스 암거 — 통로 1·2련, 수로 1·2·3련 (도면 200장) · 두께 · 헌치 · 피복 · 재료표 · 철근 재료표 | 도로암거표준도 (국토해양부, 2008) — **정리 중** |

### 옹벽 CSV 주요 열

| 열 | 뜻 |
|---|---|
| `type` · `sheet` | 형식 (L · T · H) · 도면 번호 |
| `H_mm` · `fill_m` · `slope` · `seismic` | 옹벽 높이 · 성토 높이 · 뒤채움 경사 · 지진 고려 |
| `fck_MPa` · `fy_MPa` · `steel` | 콘크리트 강도 · 철근 항복강도 · 강종 |
| `stem_height` · `top_width` · `front_offset` · `back_offset` · `stem_bottom` | 벽체 높이 · 상단 폭 · 전면 / 배면 경사 · 하단 폭 (mm) |
| `toe` · `heel` · `B` · `base_thk_*` | 앞굽 · 뒷굽 · 저판 폭 · 저판 두께 (mm) |
| `key_*` | 활동방지턱 |
| `mark` · `dia` · `n_per_m` · `len` · `ctc` | 철근 부호 · 직경 · 1m 당 개수 · 길이 · 간격 (한 줄 = 한 부호, 반중력식은 `n` · `L`) |

## 주의

- 사람이 도면을 읽어 옮긴 값입니다. 옮기면서 표준도 재료표와 다시 계산해 맞춰 보았지만, **설계에 쓰기 전에는 반드시 원본 표준도와 대조**하세요.
- 표준도는 그 발행 당시 기준(하중 · 재료 · 설계기준)으로 만든 것입니다. 지금 기준과 다를 수 있습니다.
- 원본 표준도의 권리는 발행처에 있습니다. 이 데이터를 쓰거나 옮길 때는 출처를 「도로 옹벽 표준도 (건설교통부)」 · 「도로암거표준도 (국토해양부, 2008)」로 적어 주세요.
